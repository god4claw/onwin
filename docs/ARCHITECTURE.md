# Архитектура решения

Android-приложение, которое расшифровывает разговор прямо на телефоне: кто, что и когда сказал. Сеть не нужна — приложение даже убирает разрешение `INTERNET` из манифеста, если его добавит какая-то библиотека.

## Из чего состоит

| Модуль | За что отвечает |
|---|---|
| `:app` | Экраны (Compose), запись с микрофона, импорт любых аудиоформатов с конвертацией в WAV 16 кГц моно, очередь обработки в foreground-сервисе, база (Room), экспорт в JSON, PDF, Markdown и TXT |
| `:speech` | Офлайн-движок: распознавание речи, разделение на спикеров, метки времени. Работает на sherpa-onnx 1.13.0 |
| `:llm` | Локальная LLM для постобработки: правка ослышек, имена спикеров, краткое резюме, протокол встречи. Работает на ONNX Runtime GenAI |

Приложение знает о движке только через интерфейс `Transcriber`: отдаёт WAV и получает события — реплики по мере готовности и финальную разметку в конце.

## Как идёт звук

```text
микрофон / файл ─► WAV 16 кГц моно
   ─► чтение кусками по 0,5 с (память не растёт с длиной записи)
   ─► АРУ только для VAD, чтобы он слышал тихого собеседника
   ─► Silero VAD: реплика закрывается после 450 мс тишины; длинная речь режется
      на куски до 25 с в самом тихом месте
   ─► GigaAM-v3 (ASR) по всему куску: текст с пунктуацией и метки времени слов
   ─► куски, записанные латиницей, перераспознаются английской моделью Parakeet
   ─► смена говорящего внутри куска — по эмбеддингам окон 1,6 с; разрез ставится
      между словами, сам звук для ASR не режется
   ─► эмбеддинг ERes2Net на реплику → онлайн-кластеризация (предварительный спикер)
   ─► конец записи: перекластеризация всех реплик разом, склейка разорванных фраз
   ─► LLM: правка реплик под защитой, имена и резюме
```

Работает в двух режимах: **живом** (реплики появляются во время записи) и **по файлу** (запись или импорт обрабатываются после «Стоп»). Пайплайн в обоих режимах один, а итоговые номера спикеров приходят в конце.

## Модели

| Модель | Зачем | Размер |
|---|---|---|
| GigaAM-v3 e2e RNN-T (Сбер), int8 | Русская речь в текст: пунктуация, регистр, числа цифрами | 232 МБ |
| Parakeet TDT 110M (NVIDIA), int8 | Английские фразы; язык определяется сам | 137 МБ |
| Silero VAD | Где в записи есть речь | 0,6 МБ |
| ERes2Net (3D-Speaker, VoxCeleb) | Эмбеддинги голоса для разделения спикеров | 26 МБ |
| CAM++ | Запасная модель эмбеддингов | 28 МБ |
| pyannote segmentation | Только для batch-режима, в приложении не используется | 1,5 МБ |
| Qwen2.5-0.5B-Instruct, int4 | Правка текста, имена, резюме, протокол | 0,9 ГБ, ставится на телефон отдельно, в APK не входит |

## Почему так

- **GigaAM-v3** сильнейшая открытая модель для русского языка. Версия RNN-T точнее CTC: на синтетике с шумом 16,2 → 15,1 % WER.
- **ERes2Net**, а не CAM++: CAM++ обучена на китайской речи и путала два женских голоса — 23 % ошибок атрибуции против 4,5 %. Мы сравнили ещё пять моделей эмбеддингов (WeSpeaker, TitaNet, CAM++ VoxCeleb), ни одна не оказалась лучше.
- **VAD-пайплайн вместо batch-диаризации sherpa-onnx.** Он точнее, вдвое быстрее и не падает: batch роняет процесс на записи с одним говорящим.
- **Английский — по латинице в выводе GigaAM.** Отдельная модель определения языка не понадобилась: правило не сработало ложно ни на одной из 70 русских записей.
- **LLM-правки проходят через защиту.** Если модель меняет больше 10 % символов, правка откатывается: маленькая модель любит «улучшать» правильный текст.
