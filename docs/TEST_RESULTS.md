# Результаты собственных тестов

## Как мерили

- **Где:** эмулятор Android 16 (API 36), x86_64, 4 ядра. Бенчмарк гоняет файлы через тот же `SherpaVadTranscriber`, что и приложение.
- **WER** считается после нормализации: нижний регистр, ё → е, без пунктуации.
- **Ошибка атрибуции** — доля времени речи, приписанного не тому спикеру, при лучшем сопоставлении спикеров. Лишний найденный спикер тоже считается ошибкой.
- **Наборы:**
  - живые голоса: 24 диалога трёх актёров корпуса Dialogs: чистый звук, шум, дальний микрофон;
  - синтетика: 45 разговоров 1–4 человек, озвученных TTS: шум, кафе, группы, быстрые смены реплик;
  - английский: 73 фразы LibriSpeech;
  - смешанные: 6 русских диалогов с английскими вставками;
  - длинная запись: 76 минут подряд;
  - наложения: 24 диалога с перебиваниями.

## Итог

| Набор | WER | Атрибуция (медиана) | Спикеров верно | Начало реплики, медиана |
|---|---|---|---|---|
| Живые диалоги (24) | **3,7 %** | 2,3 % | 23 из 24 | 0,14 с |
| Синтетика (26) | 15,1 % | 0,7 % | 17 из 26 | ~1 с* |
| Синтетика, контроль (19) | 17,8 % | 7,2 % | 10 из 19 | ~1 с* |
| Длинная запись, 76 мин | **3,66 %** | 2,4 % (одно соответствие на весь час) | 3 из 3 | — |
| Английский (73 фразы) | **5,6 %** (было 69,9 %) | — | — | — |
| Смешанные RU+EN (6) | **7,0 %** (было 17,5 %) | — | — | — |

\* В TTS-эталоне границы реплик включают дыхание и тишину вокруг фразы. Наши границы ближе к самой речи, поэтому на синтетике расхождение больше.

**Числа:** верно по значению 93 % («двадцать пять» = «25»).

**Скорость:** RTF около 0,2, то есть час аудио обрабатывается примерно за 12–15 минут. Память (PSS) 530 МБ, с английской моделью до 890 МБ. На длинной записи память держится в пределах 570–700 МБ и не растёт.

## Что сравнивали и что выбрали

| Решение | Было → стало |
|---|---|
| GigaAM e2e RNN-T вместо CTC | WER: живые 3,81 → 3,70 %, синтетика 16,2 → 15,1 %, контроль 19,5 → 17,8 % |
| ERes2Net вместо CAM++ | Атрибуция на живых диалогах 23 → 4,5 % |
| ASR по всему куску, разрез длинной речи в тишине | WER на живых диалогах 7,4 → 3,9 % |
| Финальная перекластеризация спикеров | Атрибуция на отложенной выборке 25,1 → 12,7 % |
| Английский через Parakeet | Английский 69,9 → 5,6 %, смешанные 17,5 → 7,0 %, русские без изменений |
| Склейка разорванных фраз | Лишних заглавных посреди фразы 39 → 0 на 70 файлах |
| Перекластеризация длинной сессии | 20 000 реплик с неверными онлайн-метками: верно 33,6 → 100 % |

**Проверили и не взяли:**
- шумоподавители GTCRN и DPDFNet: −0,1 п.п. WER, в пределах шума;
- пять других моделей эмбеддингов: ни одна не лучше ERes2Net;
- Zipformer вместо Parakeet для английского: хуже и без пунктуации;
- RNN-T без пунктуации: на одновременной речи выбрасывает фразы.

## Где слабо

- **Наложения речи:** при 7 % времени с одновременной речью WER 3,7 → 13 %, вставки у правильного спикера в 27 % случаев.
- **Группы из 3–4 человек:** число спикеров верно примерно в трети групповых файлов.

Подробности по каждому замеру — в [`docs/benches/`](benches/).
