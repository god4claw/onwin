# Английская речь без выбора языка

## Итог

Язык определяется сам, по выводу GigaAM. Русская модель пишет английскую речь
латиницей «на слух» («Ask now wey your cuntry canduffery you»), русскую —
кириллицей, бренды в русской фразе — одним-двумя латинскими словами. Поэтому:

1. Кусок, который GigaAM записала больше чем на 90 % латиницей (≥ 8 букв),
   целиком перераспознаётся английской моделью Parakeet TDT 110M.
2. Иначе ряд из ≥ 4 латинских слов подряд (≥ 15 букв) внутри куска — английская
   фраза рядом с русской речью: этот участок аудио (± 0,3 с, не заходя на соседние
   слова) распознаётся Parakeet, её слова заменяют слова GigaAM.

Отдельная модель определения языка не понадобилась. Parakeet грузится при первой
английской фразе: русские записи на неё ни памяти, ни времени не тратят.

## Хост: одинаковая VAD-нарезка, e2e RNN-T

| Набор | только GigaAM | маршрутизация |
|---|---|---|
| русские (70 файлов) | 7,28 % | 7,29 % — ни одного ложного срабатывания на уровне куска |
| английский (LibriSpeech, 73 фразы, 8 мин) | 69,9 % | **5,6 %** |
| смешанные RU+EN (6 диалогов, 30 английских вставок) | 17,5 % | **7,0 %** |

- Решение только по куску целиком на смешанных давало 12,7 %: английская фраза и
  русский ответ другого человека часто попадают в один VAD-кусок (пауза короче,
  чем нужно VAD). Отсюда второе правило — по участкам.
- Только по участкам — английский 12,2 %: кусок целиком дробился по неточным
  границам слов GigaAM. Отсюда первое правило — целиком, если почти всё латиницей.
- Бренды в русской фразе (Exxon Mobil, iPhone или Android) не трогаются: 4 слова
  подряд латиницей в 70 русских файлах не встретились.

## Parakeet против Zipformer small

| | Parakeet TDT 110M | Zipformer small |
|---|---|---|
| английский | **5,6 %** | 7,2 % |
| смешанные | 7,0 % | 6,7 % |
| файлы | 136 МБ | 28 МБ |
| RTF на хосте | 0,029 | 0,018 |
| вывод | пунктуация и регистр | заглавные, без пунктуации |

Zipformer small обучена только на LibriSpeech — на том, на чём мы её и мерили,
и всё равно хуже; Parakeet — на 36 тыс. ч разной английской речи. Выигрыш
Zipformer на смешанных (≈ 550 английских слов) — в пределах шума. Взята Parakeet.

## Эмулятор

| Файл | только GigaAM | с английским |
|---|---|---|
| смешанный диалог (clean) | 18,1 % | **2,2 %** |
| смешанный диалог (noise) | 20,5 % | **4,8 %** |
| английская фраза LibriSpeech | 76,0 % | **0,0 %** |

Английский голос в смешанных диалогах получает свою метку спикера (3 из 3). PSS с
загруженной Parakeet — 590–890 МБ против ~530 МБ без неё; первая английская фраза
приходит на 1–2 с позже (загрузка модели).

## Ограничения

- Отдельные английские слова в русской фразе («давай этот deploy») остаются на
  GigaAM — правило срабатывает с 4 слов подряд.
- Английский набор — начитанная речь одного диктора; смешанные файлы склеены
  искусственно. Разговорный английский с разными голосами не проверялся.
