# Работа с расшифровкой

Откройте готовую запись и нажмите карандаш рядом с таймкодом нужной реплики. Исправьте текст и нажмите «Сохранить». Нажатие на текст реплики перематывает аудио к её началу.

Правки сохраняются локально. При следующем экспорте в документ используется обновлённая расшифровка с прежними таймкодами.

Чтобы выбрать формат экспорта, нажмите круглую кнопку с папкой справа от кнопки воспроизведения.

Во время воспроизведения текущая реплика подсвечивается и отмечается надписью «Сейчас звучит». Подсветка плавно появляется и затухает. Список следует за аудио до ручной прокрутки. Чтобы снова включить следование, поставьте аудио на паузу и возобновите воспроизведение.
