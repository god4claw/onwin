# OnWin

Android-приложение для офлайн-расшифровки разговоров. Записывает или импортирует аудио, разделяет реплики по говорящим и добавляет временные метки. Обработка выполняется на устройстве.

## Возможности

- Запись с микрофона, в том числе в фоне, и импорт аудиофайлов.
- Расшифровка во время записи или после её завершения; поддержка русского и английского языков.
- Воспроизведение аудио, редактирование реплик и переименование спикеров.
- Локальная LLM для коррекции текста, резюме, предложений имён и протокола встречи.
- Экспорт расшифровки в JSON, PDF, Markdown и TXT; протокола — в Markdown.

## Установка

Готовый APK доступен на [странице релизов](https://github.com/god4claw/onwin/releases). Требуется устройство **arm64-v8a с Android 10 или новее**. APK занимает около 1 ГБ; при первом использовании LLM потребуется ещё около 838 МиБ для модели.

Для сборки из исходников нужны Android SDK 37, JDK 25 для Gradle daemon и архивы моделей. Подробные шаги — в [инструкции по установке и использованию](docs/INSTALLATION_AND_USE.md).

## Что важно знать

- При одновременной речи часть слов может теряться; разделение спикеров в группах работает менее надёжно, чем в диалогах.
- Резюме, имена и правки LLM могут быть неточными; их стоит проверять. Улучшение качества расшифровки после коррекции пока не измерено.
- Производительность измерялась на эмуляторе; замеров на arm64-телефоне пока нет.
